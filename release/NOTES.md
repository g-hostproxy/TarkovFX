## TarkovFX v1.3.0

**Download `TarkovFX-v1.3-win64.zip`, unzip it, and run `TarkovFX.exe`.** First time? Open the **Setup** tab and get every item green.

### New
- **"APO isn't active" warning:** TarkovFX now checks whether Equalizer APO is installed on the headset you're actually using (and whether Windows "Disable all enhancements" is blocking it). If not, you get a red banner with a button that opens Device Selector.
- **Footstep Max preset (slot 2):** cuts wind and low rumble hard, lifts 2.5 kHz where steps and gear sit, and rolls off rain/wind hiss.
- **TarkovFX Pro (slot 1, locked):** the flagship preset, retuned with a gentler compressor and auto release, so there's no pumping while sprinting.
- **Make-up gain** control after the compressor (Compressor tab).
- **Restart audio** button in Setup, as an alternative to rebooting after Device Selector changes.

### Requirements
Equalizer APO, ReaPlugs VST x64 (`reacomp-standalone.dll`) and LoudMax VST (`LoudMax64.dll`). See the README for links.
